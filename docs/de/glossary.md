| Begriff | Englisch | Bedeutung in diesen Notizen |
| --- | --- | --- |
| ADR | ADR | Architekturentscheidung (Architecture Decision Record): ein kurzes Dokument, das eine Entscheidung mit ihrem Kontext und ihren Konsequenzen festhält. |
| AFTA | AFTA | Das nationale Verfahren Irans zur Sicherheitsevaluierung von IT-Produkten. GraphBPMS Version 2 verfügt über eine Evaluierung der Stufe 1. |
| Aktion | Action | Eine Entscheidungsschaltfläche an einem User Task (genehmigen, ablehnen, zurückgeben …), die an einen ausgehenden Sequenzfluss gebunden ist. |
| BAM | BAM | Business Activity Monitoring: Leistungskennzahlen, Engpässe und Verzögerungen laufender Prozesse. |
| Berechtigungseintrag auf Datensatzebene | Record grant | Eine Berechtigungszeile, die Operationen auf genau einem bestimmten Datensatz erlaubt oder verbietet. |
| BPMN 2.0 | BPMN 2.0 | Die Standardnotation für Geschäftsprozesse, die der Designer und die Engine umsetzen. |
| C4-Modell | C4 model | Eine Methode, Softwarearchitektur auf vier Ebenen zu beschreiben: Systemkontext, Container, Komponenten und Code. |
| Call Activity | Call activity | Ein Schritt, der einen anderen Prozess als untergeordnete Instanz startet und auf ihn wartet. |
| DMN | DMN | Decision Model and Notation: der Standard für Entscheidungstabellen, genutzt von Business Rule Tasks. |
| Instanz (Prozessinstanz) | Instance | Eine Ausführung einer Prozessversion. |
| Jalali-Kalender | Jalali calendar | Der persische Sonnenkalender, der in jedem Formular, jedem Bericht und jedem Timer-Zeitplan der Plattform verwendet wird. |
| Kopie zur Kenntnis | Copy | Ein Work Item, das nur zur Information gesendet wird. Es erfordert keine Aktion. |
| Lane | Lane | Eine BPMN-Lane. Ihre Regeln bestimmen, wer die Work Items der darin liegenden Schritte erhält. |
| Öffentliches Formular | Public form | Ein Formular, das Personen außerhalb der Organisation ohne Benutzerkonto absenden können. |
| Organisation | Organization | Die Mandanteneinheit innerhalb einer Installation. Benutzer können mehreren Organisationen angehören. |
| Posteingang | Inbox | Die Liste der offenen Work Items eines Benutzers für seine aktive Stelle und Organisation. |
| Provider | Provider | Ein benannter, parametrisierter Konnektor zu einer SQL-Quelle, einem REST-Dienst oder einem SOAP-Dienst, der modulübergreifend wiederverwendet wird. |
| Prozessgruppe | Process group | Die stabile Identität eines Prozesses über alle seine Versionen hinweg. |
| Prozessversion | Process version | Ein veröffentlichtes, unveränderliches Diagramm einer Prozessgruppe. |
| Rollengruppe | Role group | Eine Rolle, die immer zusätzlich zur aktiven Stelle gilt. |
| Service Bus | Service bus | In dieser Plattform: HTTP-Endpunkte, die einen Provider oder einen Prozess für andere Systeme bereitstellen. |
| SSE | SSE | Server-Sent Events: eine unidirektionale, langlebige HTTP-Response, die für Echtzeitbenachrichtigungen genutzt wird. |
| Stelle | Position | Eine Rolle, die einen Posteingang besitzt. Ein Benutzer hat zu jedem Zeitpunkt genau eine aktive Stelle. |
| Testumgebung | Test environment | Eine Sandbox innerhalb der Produktion, in der ein Prozessentwurf läuft, unsichtbar für echte Benutzer. |
| Vertretung | Delegation | Die Übergabe des eigenen Posteingangs an einen anderen Benutzer oder eine Rolle für eine Prozessgruppe und einen Zeitraum. |
| Wartezustand | Wait state | Ein Element, an dem die Engine anhält und den Zustand persistiert: User Task, Receive Task, empfangendes Ereignis (Catching Event), Timer, Call Activity. |
| Work Item | Work item | Ein Schritt einer Instanz für einen Empfänger. |
| Zentralorganisation | Central organization | Die Organisation, die in einer Installation mit mehreren Organisationen die plattformweite Administration innehat. |
